# FarFISH Android App Setup Guide

## Requirements

- **JDK 21** (Required)
- **Android Studio** Hedgehog or later
- **Android SDK** API 28+ (Android 9.0+)

## First-Time Setup

### 1. Install JDK 21

Download and install JDK 21 from:
- [Oracle JDK 21](https://www.oracle.com/java/technologies/downloads/#java21)
- [OpenJDK 21](https://adoptium.net/temurin/releases/?version=21)

Verify installation:
```bash
java -version
```
Should output: `java version "21.x.x"`

### 2. Configure Android Studio

1. Open Android Studio
2. Go to **File → Project Structure → SDK Location**
3. Set **Gradle JDK** to JDK 21

### 3. Create local.properties

Create `local.properties` in the `android-app` folder:

```properties
sdk.dir=C\:\\Users\\YourUsername\\AppData\\Local\\Android\\Sdk
```

Replace `YourUsername` with your actual Windows username.

### 4. Sync Project

1. Open the `android-app` folder in Android Studio
2. Click **File → Sync Project with Gradle Files**
3. Wait for sync to complete

## Build the APK

### Debug Build (for testing)
```bash
cd android-app
gradlew.bat assembleDebug
```
Output: `app\build\outputs\apk\debug\app-debug.apk`

### Release Build (for distribution)
```bash
cd android-app
gradlew.bat assembleRelease
```
Output: `app\build\outputs\apk\release\app-release.apk`

## Install on Device

### Via ADB
```bash
adb install app\build\outputs\apk\debug\app-debug.apk
```

### Via Android Studio
1. Click **Run → Run 'app'**
2. Select your device
3. Click **OK**

## Configuration

### Change Web App URL

Edit `app\build.gradle`:
```gradle
buildConfigField "String", "APP_URL", "\"https://farfish.vercel.app\""
```
(Already configured correctly)

### Change App Name

Edit `app\src\main\res\values\strings.xml`:
```xml
<string name="app_name">Your App Name</string>
```

### Update Version

Edit `app\build.gradle`:
```gradle
versionCode 1        // Increment for each release
versionName "1.0.0"  // User-facing version
```

## Troubleshooting

### JDK Version Error
If you get a JDK version error:
1. Verify JDK 21 is installed: `java -version`
2. Update Android Studio's Gradle JDK setting
3. Set `JAVA_HOME` environment variable to JDK 21 path

### SDK Not Found
Create `local.properties` with correct path to your Android SDK.

### Gradle Sync Failed
1. Check internet connection
2. Run: `gradlew.bat clean`
3. Click **File → Invalidate Caches → Restart** in Android Studio

### Build Failed
1. Clean build: `gradlew.bat clean`
2. Rebuild: `gradlew.bat assembleDebug`
3. Check Logcat for errors
